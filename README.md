# 网易云音乐歌词与字幕提取器 - 使用指南

一款专为音乐爱好者、双语学习者及视频剪辑创作者打造的网易云音乐歌词与字幕提取工具。支持轻松导出播放器专用的 **`.lrc` 歌词** 以及视频制作通用的 **`.srt` 字幕**。

---

## 🌟 核心功能

1. **链接自动识别**：
   - 支持粘贴网易云音乐网页版链接；
   - 支持直接粘贴手机 App 复制的分享文案或短链接；
   - 支持直接输入纯数字歌曲 ID。

2. **动态内容轨道与自由排序**：
   - 获取歌词后，软件会自动识别当前歌曲包含的语言层（**原文**、**读音**、**译文**），歌曲有哪几层就展示哪几块；
   - **鼠标拖拽卡片**即可自由调整上下排列顺序（例如：将中文放在上面、原文放在下面，或是将日文读音放在最上方）；
   - 每个卡片左侧均有**独立开关**，随时勾选或取消勾选以显示或隐藏某一层。

3. **双格式支持 (LRC / SRT)**：
   - **LRC 歌词**：适配主流音乐播放器，支持多行同时间戳显示或单行斜杠合并显示；
   - **SRT 字幕**：适配视频剪辑软件（剪映、Premiere、Final Cut Pro、达芬奇、CapCut 等），可直接自定义单句字幕的最长停留时间（支持小数，如 `4.2` 秒）。

4. **实时预览与文本编辑**：
   - 任何排版变动、格式切换均在右侧窗口**即时渲染呈现**，所见即所得；
   - 支持在预览窗口中直接**手动修改文字**；
   - 编辑支持快捷键：**`Ctrl + Z` 撤销**，**`Ctrl + Y` 或 `Ctrl + Shift + Z` 重做**。

5. **便捷导出**：
   - 支持一键复制全部文本到剪贴板；
   - 支持导出当前格式文件；
   - 支持点击「同时导出 LRC+SRT」一键把歌词和字幕一并保存到指定文件夹。

---

## 📖 详细使用说明

### 第一步：打开软件
- 在文件夹中直接双击运行 **`run_gui.bat`**（或直接双击打包好的可执行文件程序）。

### 第二步：输入歌曲并解析
1. 打开网易云音乐，复制歌曲的分享链接；
2. 切换回本软件，点击输入框旁的 **「粘贴」** 按钮；
3. 点击 **「获取并解析歌词」**。

### 第三步：调整语言排版与顺序
歌曲解析成功后，左侧的「内容轨道与顺序」板块将自动生成当前歌曲拥有的卡片（例如【原文】、【读音】、【译文】）：
- **调整上下层级**：用鼠标按住卡片直接向上或向下拖动，或点击右侧的 `▲` / `▼` 按钮微调；
- **显示/隐藏某层**：勾选或取消勾选卡片前的复选框。右侧预览区域将立即跟随变化。

### 第四步：设置导出格式
- **选择导出格式**：在「导出格式」中选择 **`LRC 歌词 (.lrc)`** 或 **`SRT 字幕 (.srt)`**；
- **若选择 SRT 字幕**：可直接在「单句最长保留时间」后输入想要的时长（例如输入 `4.5` 或 `5.0` 秒）；
- **若选择 LRC 歌词**：可在下拉框中切换展现样式（推荐使用“多行同时间戳”）。

### 第五步：预览调整与保存文件
1. **右侧实时预览**：
   - 在右侧大文本框中检查歌词/字幕效果；
   - 如需手动调整字词，可直接在框内打字修改（按 `Ctrl+Z` 可随时撤回修改，按 `Ctrl+Y` 可恢复重做）。
2. **导出到电脑**：
   - 点击 **「复制内容」**：直接将文字拷贝到剪贴板；
   - 点击 **「导出当前文件」**：单独保存当前的 `.lrc` 或 `.srt` 文件；
   - 点击 **「同时导出 LRC+SRT」**：选择保存目录，一次性将两种格式全部保存。

## 💡 常见疑问解答

* **问：为什么有的歌曲只显示【原文】和【译文】，没有【读音】卡片？**
  * 答：软件会根据网易云官方实际包含的数据动态展示。英文歌、中文歌通常本身没有罗马音/读音注音，因此程序会自动隐藏该卡片，只保留实际存在的内容。

* **问：导出的 SRT 字幕怎么在视频剪辑软件里使用？**
  * 答：将导出的 `.srt` 文件直接拖拽进剪映、Premiere、Final Cut Pro 或达芬奇的轨道中，软件即可自动识别并对齐视频时间轴。
